# Project: MEGA
## About
 `Project: MEGA` is a hack rom based on HG Engine with a focus on bringing a better overall experience than original HGSS games, which includes an updated battle engine with more mechanics, both from newer games and made from scratch, new places to explore and a brand new plot.
